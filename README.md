# 地球たんけん — arearth

国旗や世界の見どころを選んで、地球を回すWeb地球儀です。対応スマートフォンでは、ARで机や床に置けます。

**公開ページ：https://kagoya.github.io/arearth/**

## 使い方

1. 初回は「かんたん」で開きます。国の名前と国旗を表示します。過去の表示設定があれば保持します。
2. 国のボタンや検索結果から場所を選びます。選んだ地点が地球の正面になります。ひらがな・カタカナ・英語でも検索できます（一部の漢字地名に読みを追加）。
3. 国の名前・国旗・まち（首都）・見どころ・世界いさんのチェックを組み合わせます。近くの場所だけにも絞れます。
4. iPhoneのSafari、対応AndroidのChromeでARボタンを押し、机や床を映して地球を置きます。選んだ地点が最初に正面を向き、拡大すると文字や旗も大きくなります。

「くわしく」では境界線・選択地点の輪・文字や国旗の大きさ・周辺の広さ・重なりの自動調整・表示プリセット・座標と出典を使えます。モードを切り替えても選択や表示設定は変わりません。モードと表示設定をブラウザに保存します。

## 内容

- 国・地域242件、首都25件、観光地600件（全242地域に1件以上）
- 世界遺産1,273件を独立した表示・検索項目として収録
- 239地域の国旗画像
- 改行・縁取り・引き出し線・衝突回避。選択した地点を優先し、読めない重なりは省略
- 検索結果を40件ずつ表示。ラベルの衝突判定に空間グリッドを使用
- 国名と国旗は実際のテクスチャに焼き込み、WebXR・iPhone Quick Lookにも反映

AR中の設定変更はページに戻って行ってください。回転・拡大操作は端末のARビューアに従います。WebGL非対応環境では、選択地点を正面にした画像を表示します。

## 開発と確認

外部パッケージのインストールやビルドは不要です。ルートを静的HTTPサーバーで配信してください。

```sh
npm run check
```

32通りのレイヤー組み合わせ、地名の重なり、近傍フィルター、データ件数・国別カバー、ひらがな検索、2,140地点のAR正面向きと北向き、GLBの埋め込み画像を検証します。実際のカメラAR操作は対応する実機で確認してください。

GitHub Pagesは`main`ブランチのルートから公開します。`.nojekyll`を含み、すべてのアセットは相対パスです。データの選定と出典は[DATA_SOURCES.md](DATA_SOURCES.md)、ライセンスは[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)を参照してください。
